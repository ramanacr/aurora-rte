# Aurora Editor Brand Kit

## Brand essence

Aurora Editor is modern, luminous, precise, and flexible. The ribbon-A mark represents expressive composition; the central cursor conveys editing, focus, and developer-friendly integration.

## Captions

- **Compose without limits** — primary tagline.
- **Built to belong** — white-labeling and seamless product integration.
- **Fast by design** — performance and responsive authoring.

## Usage rules

- Keep the mark clear of nearby text and UI controls by at least one-third of its width.
- Use the transparent mark on simple, high-contrast surfaces; use the app icon on dark application chrome.
- Do not recolour individual ribbon segments, stretch the mark, add another symbol inside it, or place it over visually busy content.
- Use “Aurora Editor” as the full product name; use “Aurora” only where product context is already clear.

## Note

These are raster production concepts. Before trademark filing or final design-system lock, recreate the accepted mark as a clean vector SVG and run a formal uniqueness/trademark review.
