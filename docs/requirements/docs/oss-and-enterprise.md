# Open-Source and Enterprise Boundary

## Core promise

The Apache-2.0 core includes complete rich-text editing, integration bridges, extension SDK, custom blocks, themes, localization, safe import/export, and basic comments. It works without registration, telemetry, backend, or commercial package.

## Enterprise value

Commercial modules deliver suggestion workflows, persistent review, audit history, templates/assets, versions, document comparison, SSO/RBAC/tenancy, managed/self-hosted operations, collaboration, offline sync, tracked changes, DOCX conversion, governed AI, and support.

## Enforcement

Keep commercial packages in an access-controlled workspace or repository. Core builds/tests independently. Enterprise code extends public contracts only; license activation never degrades core content. Obtain legal review for trademarks, contributor agreement, notices, and commercial terms.
