# Deployment Guide

## Core

Publish signed ESM packages with TypeScript declarations, source maps, integrity metadata, and tree-shakable export maps. Supply CDN-ready Web Component bundles and npm packages. No API key, account, or network connection is required.

## Enterprise

Deliver identical public service APIs through managed cloud and self-hosted images. Self-hosting needs documented OIDC/SAML, storage, database, encryption-key, tenant-isolation, backup, logging, metrics, and upgrade configuration. Customer document content must not cross deployment boundaries.

## Operations

Provide health/readiness endpoints, redacted structured logs, OpenTelemetry-compatible telemetry, versioned database migrations, rolling-upgrade compatibility, restore drills, incident response, and data-residency/retention documentation.
