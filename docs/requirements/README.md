# Aurora Editor Documentation Pack

Aurora Editor is a proposed Apache-2.0, framework-neutral rich-text editor platform for business SaaS. It is client-side by default, white-labelable, fast, accessible, and extensible. Commercial modules add organization-scale review, governance, and optional managed/self-hosted services.

## Start here

1. Read [the approved design](docs/superpowers/specs/2026-08-27-rich-text-editor-design.md).
2. Read [the working guide](docs/working-guide.md) and [coding-agent instructions](docs/coding-agent-instructions.md).
3. Select one plan: [core editor](docs/superpowers/plans/2026-08-27-core-editor.md), [integration ecosystem](docs/superpowers/plans/2026-08-27-integration-ecosystem.md), or [enterprise services](docs/superpowers/plans/2026-08-27-enterprise-services.md).
